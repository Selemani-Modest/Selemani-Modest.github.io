## 🚀 Deployment (GitHub Pages)

1. Create this repository: `Selemani-Modest.github.io`
2. Push `index.html`, `robots.txt`, and `sitemap.xml` to the default branch
3. Go to **Settings → Pages** and confirm the branch is selected
4. Your site is live at `https://selemani-modest.github.io/`

**After deploying**, submit the URL in
[Google Search Console](https://search.google.com/search-console) to speed up indexing.
